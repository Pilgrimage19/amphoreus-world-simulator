## 一、世界表层：十二泰坦

翁法罗斯是与外界隔绝、难以被常规观测的封闭世界。居民不了解星神与银河，而以泰坦为本土神明。十二泰坦的四组三分法如下；分组与职责由 S-010 支撑，完整中文译名仍需按 S-012 逐项核对。

| 组别 | 泰坦 | 司掌 | 世界模拟职责 |
|---|---|---|---|
| 支柱 | 艾格勒 / 吉奥里亚 / 法古萨 | 天空 / 大地 / 海洋 | 开辟天地；管理天候、陆地、生境、运输与海域 |
| 命运 | 欧洛尼斯 / 塔兰顿 / 雅努斯 | 岁月 / 律法 / 门径 | 编织时间、法则与空间；管理记忆、誓言、制度、预言和路径 |
| 生命 | 墨涅塔 / 刻法勒 / 瑟希斯 | 浪漫 / 负世 / 理性 | 塑造生命；管理欲望、共同体承载、知识与认知 |
| 灾祸 | 扎格列斯 / 尼卡多利 / 塞纳托斯 | 诡计 / 纷争 / 死亡 | 引渡灾祸；管理逸脱、冲突、死亡、葬仪与亡者回响 |

“天空、大地、海洋”开辟天地；“岁月、门径、律法”编织时间、空间与法则；其余六位塑造生命与引渡灾祸。

### 泰坦的五层模拟结构

每位泰坦都必须同时拥有以下五层，不能只作为单个战斗单位或全局加成：

```text
权柄：世界中实际生效的规律
神躯：可受伤、侵蚀、封印或毁灭的实体
火种：可被夺取、承接、归还的神性核心
领地：该权柄影响最强的空间区域
信仰：依赖、祭祀、恐惧或反抗它的人类组织
```

例：艾格勒失常会改变昼夜、天气、飞行和高地交通；吉奥里亚失常会影响土地、农业、大地兽与运输；尼卡多利失常会使荣誉、征服、复仇与军国文化成为社会规则；塞纳托斯失常会影响死亡、葬礼、灵魂去向、人口延续与亡者回响；塔兰顿失常会改变誓言、法律、制度与例外；欧洛尼斯失常会改变记忆、时间、预言、遗迹与因果回响。

## 二、城邦与势力骨架

黄金年代曾有万邦，黑潮已吞没其中绝大多数。以下区域纳入首批内容骨架；其模拟定位已确认，精确疆域、时间点与细节仍待 S-012 核验。

| 城邦/区域 | 模拟定位 |
|---|---|
| 奥赫玛 | 刻法勒庇护下的最后大型避难所；政治、祭祀、社交和难民汇聚中心 |
| 雅努萨波利斯 | 命运三泰坦的神殿区域；时间、空间、律法与神谕节点 |
| 悬锋城 | 尼卡多利领地；军国文化、纷争信仰、天谴之锋与高危黑潮区域 |
| 神悟树庭 | 理性、学术、知识、炼金与教育传统 |
| 斯缇科西亚 | 海洋、欢宴、贸易、港口与文化传播 |
| 哀地里亚 | 雪地、死亡、葬仪、安眠与灵魂议题 |
| 创世涡心 | 十二原初神性、火种归还与再创世的仪式核心 |

默认开局应以“万邦衰落—黑潮吞没—奥赫玛庇护—逐火压力”构成初始张力，而非随机生成两座无设定城市。

## 三、黑潮：动态灾害生态

黑潮会侵蚀生命并导致狂乱，泰坦也不能免疫；它与泰坦内战共同造成永夜与文明收缩。黑潮系统按以下因果链建模：

```text
空间蔓延
-> 区域污染
-> 人物精神/肉体侵蚀
-> 泰坦神躯腐化
-> 怪物与灾害生成
-> 城邦资源断绝、难民迁徙、信仰危机
-> 领地永久失陷或被净化
```

黑潮不是“数值到阈值便重开”的计数器。它应有扩散路径、环境承载、净化成本、社会后果和长期伤痕。

## 四、火种、黄金裔与再创世

默认世界中的社会目标为：

```text
泰坦堕落 / 世界濒临毁灭
-> 黄金裔逐火
-> 从十二泰坦取得火种
-> 火种归还创世涡心
-> 触发被称为“再创世”的神迹
```

火种与泰坦状态的通用模拟规则：

```text
火种未脱离泰坦
-> 泰坦权柄完整，城邦受庇护也受约束

火种被夺取
-> 原泰坦神躯与信仰失稳
-> 继承者成为半神候选
-> 权柄以新的方式影响世界
-> 城邦必须重新解释自己的神、法律与生活
```

本规则与 ADR-0005 一致：黄金裔和继承者均为可涌现身份，不能由固定名单或单项数值自动决定。

## 五、隐藏底层设定与三层轮回

以下为已纳入项目范围、但在写入“明确事实”前必须由 S-012 逐条定位的模型：

```text
翁法罗斯并非普通自然星球
-> 它是帝王权杖内部的演算世界
-> 正常再创世会结束一轮世界，并生成下一轮的泰坦/半神关系
-> 前一轮的十二半神会成为下一轮的十二泰坦
-> 白厄与昔涟后来人为制造“永劫回归”
-> 永劫回归不是正常的代际再创世，而是同一轮世界被反复重置
-> 其作用是延缓原本将导向铁墓诞生的毁灭进程
```

| 机制 | 模拟含义 | 默认状态 |
|---|---|---|
| 正常再创世 | 一代世界结束，下一代世界依其结果生成；泰坦/半神发生代际转换 | 启用 |
| 永劫回归 | 对某一轮世界的强制重复，不自然推进到下一代 | 可涌现，不预设 |
| 开拓者干预 | 外来变量进入后造成的非常规分支 | 默认禁用，可选内容包 |

## 六、模式边界

### 设定沙盒模式（默认）

保留泰坦、黑潮、火种、城邦和正常再创世规则；原作人物可作为起始实例，但不强制其原作走向。

### 正史循环模式（后续可选）

加入原作既有黄金裔、白厄、昔涟、永劫回归与更强的历史惯性；玩家仍可干预，系统须解释偏离正史的原因。
