# 设定考据库

本目录是“原作事实”进入设计的唯一入口。任何规则在标为原作设定前，必须先在这里有记录。

## 记录规则

- `明确`：能在官方游戏文本、剧情、官网或官方节目中直接验证；
- `强推断`：由多条明确事实支持，但原作未直接表述；
- `弱推断`：方便讨论的解释，不能成为不可替代的核心机制；
- `项目原创`：为了可玩性补完的规则，必须明确说明。

社区文章只能作为线索，不能单独将条目提升为“明确”。每个来源需标记版本及剧透级别。
