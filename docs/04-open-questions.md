# 当前假设、风险与待决问题

状态：持续维护  
最后更新：2026-09-04

## 已采用假设

| 编号 | 假设 | 若错误的影响 | 验证方式 |
|---|---|---|---|
| A-001 | 玩家接受低画质与符号化地图 | 若不接受，客户端成本上升 | 早期可视化试玩 |
| A-002 | 玩家愿意先观察再干预 | 若不接受，需要更强任务驱动 | 原型盲测 |
| A-003 | 有损轮回比完整继承更有情感重量 | 可能造成挫败或觉得白玩 | A/B规则测试 |
| A-004 | 结构化规则可产生足够多的终态 | 若失败，需要增加系统耦合或手工事件 | 批量模拟统计 |
| A-005 | 少量完整人物足以承载情感 | 若失败，需要提高人物模拟密度 | 叙事回忆测试 |

## 主要风险

| 风险 | 概率 | 影响 | 当前对策 |
|---|---:|---:|---|
| 范围失控，试图一次覆盖完整设定 | 高 | 极高 | 微型轮回作为唯一首期目标 |
| 系统复杂但玩家看不懂 | 高 | 高 | 事件、因果链和历史界面前置设计 |
| 随机结果很多但缺乏意义 | 中高 | 高 | 关系、誓言、代价和跨世记忆 |
| 某个机制支配所有结局 | 高 | 高 | 无头批量模拟与分布检查 |
| 更新导致旧种子无法复现 | 高 | 中 | 版本化随机流与回放元数据 |
| 大模型产生幻觉或事实冲突 | 中 | 中 | 只读事件输入、输出校验、可关闭 |
| 同人IP内容被要求移除 | 低到中 | 极高 | 通用内核与内容包隔离、自制资产 |
| 设定理解存在争议 | 高 | 中 | 来源、版本、事实/推断分栏 |

## 待决问题

### 会阻塞近期开发

- [ ] 首版开发语言与测试框架；
- [ ] 首个 tick 代表的时间尺度；
- [ ] 内容配置选 JSON 还是 YAML；
- [ ] 事件日志采用全量事件溯源还是快照加关键事件；
- [ ] 第一批三位泰坦/权柄的正式设定映射。

### 不阻塞技术骨架

- [ ] 玩家在世界内的叙事身份；
- [ ] 是否存在明确的胜利判定；
- [ ] 轮回遗产由玩家选择还是部分自动保留；
- [ ] 原作角色是固定人物、可能出现的人物原型，还是完全不直接复刻；
- [ ] 是否允许世界在没有玩家操作时打破轮回；
- [ ] 模组API与许可证选择；
- [ ] 仓库剧透组织方式。
