# Python 原型：P-0001 的实现说明

状态：实现中  
最后更新：2026-09-05

## 目的

这是纸面原型 `P-0001` 的第一个可运行版本。它优先验证确定性、事件留痕和可批量运行；尚未尝试完成完整翁法罗斯设定或图形界面。

## 当前包含

- Python 3.12 标准库，无第三方依赖；
- 根种子派生出的隔离随机流；
- 两座城邦、六名关键人物、天时/纷争/律法三项开发代号权柄；
- 粮食、人口、秩序、贸易、援助、索取、战争和黑潮；
- 结构化事件日志、状态哈希和 JSON 输出；
- 每回合世界状态输出：黑潮、三项权柄、两座城邦和六名关键人物；
- 德洛/卡尔的旧约、阿刻的共同封印、伊娅的史书保存、诺娅的停战与塞芙的牺牲；
- 同种子完全一致的自动化测试。
- 100个种子的批量回归检查，确保不同种子不会收敛为同一段历史；终态分布将在独立平衡测试中评估。

## 当前明确不包含

- 玩家命令；
- 完整的权柄继承、遗产选择与第二世初始化；
- 原作正式人名、泰坦映射或剧情复刻；
- Godot/网页/UI；
- 大模型接口。

## 运行

在项目根目录执行：

```powershell
$env:PYTHONPATH = 'src'
python -m amphoreus_sim.cli --seed 42 --ticks 20
```

保存结构化结果：

```powershell
$env:PYTHONPATH = 'src'
python -m amphoreus_sim.cli --seed 42 --json simulation-output/run-42.json
```

运行测试：

```powershell
$env:PYTHONPATH = 'src'
python -m unittest discover -s tests -v
```
