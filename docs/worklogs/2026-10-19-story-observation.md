# 2026-10-19：逐火年代记改版

## 范围与分工

按用户要求由 Luna（gpt-6-luna）实现前端，协调者负责产品契约、只读后端、代码审查、测试和集成。前两层已完成：信息架构与事实驱动的人物经历；未变更模拟规则、数值、试炼及权能，也没有实现下一代世界。

## 完成内容

- 首页世界阶段、重点指标、重大事件、人物入口、实际推进批次回顾和终局遗产；历史页重大时间轴与原始记录分层。
- 人物真实经历、可点击相关人物、能力/人格/痕迹用途说明；默认仍仅十二因子行者，在世与已故合计不超过十二。
- 长列表内部滚动、键盘可访问、动态文本转义。人物详情和世界请求丢弃过期响应；推进期间锁定操作，终局禁用推进。
- 只读投影不消费随机数；新网页采用 compact 请求头，旧客户端仍可取全量快照。其他历史人物可按 ID 查询。
- 深复制逐火史，避免返回快照被后续模拟更新；同一锁内推进并生成回顾，避免并发串批次。

## 验证

项目专属 Conda 环境完整 Python 测试 126 项通过（21.921 秒）；前端测试 10 项通过，覆盖转义、完整批次、旧接口降级、请求锁、异步竞态和在世/已故混合名册。`git diff --check` 通过。

完整新版终局页面确认三种推进按钮禁用，人物名册 12 人且包含已故行者，无横向溢出。首页截图见 `docs/audits/2026-10-19-story-overview.png`。同一旧世界全量响应约 49 MB，网页 compact 响应实测 437222 字节；完整接口保留。

浏览器独立测试世界以 seed 42、人口样本 100 推进至第 100 年，确认本批 21 个重大节点可见，包括失陷、失败挑战和五次门径救援；没有推进或重置用户原世界。

用户原 seed 42、人口样本 1000、第 1483 年世界完整旧字段与新版重放一致。第一次直接比较内部元组与 JSON 数组产生假差异，统一 HTTP JSON 表示后验证相等；不是模拟结果变化。校验摘要见同日 audit JSON。原始快照与验证缓存只在忽略目录 simulation-output 内，不上传大型存档。

本次新版预览使用 8001 端口，载入已核对的原世界副本；副本重建不冒充用户最近一次推进，因此初始批次回顾为空。原 8000 服务没有被本轮重置；临时服务若已退出不保证继续可用。
