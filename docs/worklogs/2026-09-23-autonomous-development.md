# 2026-09-23 持续开发记录

本文件记录本轮“先稳定当前模块，再继续下一模块”的实际操作。每完成并推送一个可靠检查点后更新。

## 检查点 1：网页端逻辑加固

### 审计发现

- 原有网页测试只有 2 项，仅覆盖服务对象的终局停止与重置；HTTP 路由、请求校验、静态资源、人物详情和并发均未覆盖。
- `/api/advance`、`/api/reset` 接收到数组、字符串、错误字段类型或非法 `Content-Length` 时，可能在 `.get()` 或模拟器构造阶段中断连接。
- `person_detail()` 没有与推进/重置共用世界锁，存在并发读取中间状态的可能。
- 浏览器中的人物详情在世界推进后不会刷新，重置后会残留旧世界详情。
- 推进一年、推进十年和重置三个按钮可以同时发请求，响应乱序时页面可能显示旧快照。

### 已修改

- 为 JSON 请求增加对象类型、字段类型、长度和编码校验；错误统一返回 JSON 400/413，不改变世界状态。
- 人物详情读取纳入 `WorldServer` 的可重入锁。
- 前端所有世界操作改为单一在途事务，操作期间同时禁用三个控制按钮。
- 保存人物选择并在推进后重新拉取详情；用请求版本号丢弃迟到响应；重置或人物退出十二因子焦点时清空详情。
- 终局状态独立保存，异步操作结束后不会错误地重新启用推进按钮。

### 验证

- `node --check src/amphoreus_sim/web/app.js`：通过。
- 网页专项测试由 2 项扩展到 8 项：全部通过。
- 全部自动测试：71/71 通过。
- 真实 HTTP 覆盖：状态、静态资源、单年/批量推进、1–100 年边界、重置、人物详情、404、非法 JSON、非法字段类型和并发推进。
- 真实浏览器验收：十年推进、页面切换、人物详情、推进后详情从 24 岁刷新为 25 岁、重置清除详情、历史页和控制台均正常。
- 真实终局验收：种子 42 在第 941 年崩溃后，“推进一年”和“推进 10 年”均保持禁用，重置仍可用。

## 检查点 2：天空火种闭环

### 审计与设计落实

- 初版按“高天遗迹出身 + 存护最高”筛选时，种子 42 的 31 名高天出身者仅 2 人主导存护且均未觉醒，整条世界线没有天空半神。
- 修正为出生地稳定记录；高天遗迹出生者获得存护主导倾向，保留血脉稀缺性，但不直接创建指定候选人。
- 试炼要求存护黄金裔在黑潮中五次维持避难通道，并亲历高天遗迹失陷；火种只能在失陷之后逐年完成，不会在第 20 年前速成。

### 已实现

- 天空持有者每年为当前威胁最高的未失陷城邦预警并增加防线，严重风暴累积权能负担。
- 奥赫玛首次达到不可逆失陷条件时，自动消耗天空持有者与火种，降低黑潮及残留源，恢复粮食、秩序、防线并清空本次崩溃进度。
- 天空治愈只触发一次；单元测试确认奥赫玛第二次满足同一条件时仍会正常失陷。
- 网页显示天空预警、风暴负担、治愈状态、人物出生地和天空试炼进度。

### 验证

- 全部自动测试：75/75 通过。
- 种子 42 自然回放：天空火种第 36 年承接，第 966 年为奥赫玛献祭归还。
- 1,600 年长程审计：异常 0；天空于第 966 年治愈奥赫玛，奥赫玛第 1366 年再次按通用规则失陷，世界第 1409 年崩溃，确认没有形成永久安全区。

## 检查点 3：海洋火种闭环与终局条件修复

### 审计发现

- 海洋模块此前只有设计文档，没有候选、试炼、权能、羁绊或献祭实现。
- 接入海洋试炼后的首次长程回放在第 401 年突然以“再创世准备完成”停止；原因是早期纵切遗留的“六枚火种被持有即结束”占位判断，与当前确认的十一火归还、负世最后承载顺序冲突。
- 初次献祭事件同时在通用归还事件和海洋随祭事件写入同一归还效果，审计会重复计数；已改为只有通用事件记录火种归还，随祭事件记录跟随与黑潮残留降低。

### 已实现

- 海洋候选要求共情不高于 35、虚无为最高因子、第 50 年后在斯缇科西亚黑潮中完成五次救援或撤离引航。
- 承接后与首位非负世持火半神建立双向“唯一羁绊”；负世者明确排除。
- 海洋权能每三年从最危险城邦向安全城邦开辟有限航路，最多迁移 120 人并从目的地真实库存逆运补给；出发地黑潮略降，污染转移至持有者所在地并消耗健康。
- 只有锚点主动归还火种才会触发海洋持有者跟随献祭；锚点普通死亡不会触发。随祭降低所有幸存城邦的黑潮与残留源。
- 再创世条件改为十一枚非负世火种全部归还、负世火种已有最终持有者；六枚火种仅被持有不再提前结束网页世界。
- 网页展示海洋试炼进度、羁绊对象、航行次数和污染负担；长程审计会报告同一火种重复归还。

### 验证

- 海洋专项单元测试覆盖低共情门槛、五次引航、负世锚点排除、双向羁绊、海路人口转移、污染负担、主动献祭联动及普通死亡不联动。
- 终局回归测试确认六枚持有火种不会结束世界，且十一火归还加负世承载会进入再创世终局。
- 全部自动测试：81/81 通过；`node --check src/amphoreus_sim/web/app.js` 与 `git diff --check` 通过。
- 修复终局占位条件后，种子 42 不再于第 401 年错误停止；海洋自然于第 401 年承接，建立天空半神羁绊并完成 50 次航行，在第 966 年随天空献祭归还。最终 1,600 年审计仅记录一次海洋归还，奥赫玛第 1406 年失陷、世界第 1454 年崩溃，异常 0。
- 重启实际网页服务后，以 HTTP 批量推进到第 410 年，确认网页未错误结束；真实浏览器的泰坦页正确显示法古萨持有者、唯一羁绊、3 次航行和 3 点污染负担。验收后已把网页重置到种子 42 第 0 年。

## 检查点 4：诡计火种闭环

### 已实现

- 欢愉最高的成年黄金裔须在第 50 年后进入真实紧张且组织影响力足够的权力网络；试炼依序记录制造身份面具、凭洞察与适应力揭露阴谋、公开坦白最大谎言三步。
- 公开坦白会留下誓言痕迹并降低候选人与关系网的信任；冲突行动不能代替坦白。
- 承接后每十年揭露一个不同组织的秘密，削弱组织影响力并降低当地紧张；面具负担逐年损伤持有者社交能力及关系信任。
- 揭露五个组织后，持有者死亡、诡计火种归还；幸存城邦紧张及其他泰坦腐化下降。网页展示诡计试炼阶段、揭密数和面具负担。

### 验证

- 两项诡计专项测试通过，覆盖三阶段试炼、信任代价、五组织揭密及献祭归还。
- 全部自动测试：83/83 通过；网页脚本语法和 `git diff --check` 通过。
- 种子 42、人口样本 1,000、上限 1,600 年：诡计第 69 年承接，按期揭露五个组织，第 110 年献祭归还；海洋、天空、大地也完成各自归还；世界第 1464 年崩溃，异常 0。
