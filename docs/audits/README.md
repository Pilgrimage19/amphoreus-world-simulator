- 三个自然世界均没有无暇之灵魂或完美之容器；岁月及负世缺席符合稀有候选规则。完整成功链另外通过构造测试验证，不冒称自然观察到了完美结局。
- 每年检查非负人口、粮食、样本与宏观人口关系、真实火种持有者、归还故事、重复归还、废墟不自行复活及岁月归还顺序。零异常仅说明这些检查通过，并非所有可能缺陷已排除。
- 黄金裔比例与世界寿命仍需校准；本轮优先修复结构性问题、完整接入模块，没有为制造好看的审计结果强制产生候选或提前归还。
