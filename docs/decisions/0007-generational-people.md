# ADR-0007：采用代际人物与亲属关系传承

状态：接受  
日期：2026-09-06

## 背景

匿名“新生儿”虽能维持人口数量，却没有亲属、社会关系、成长阶段或叙事来源；若直接按影响力选取历史焦点，会造成后期历史被无背景人口占据。

## 决定

- 新生人物必须从一对具备稳定双向关系的本地成年人中产生；
- 子女继承父母的因子倾向，并拥有双亲、亲属誓言与少量家庭社会联系；
- 人物按儿童、青年、成人、长者分阶段；儿童只成长与学习，不执行成年人的公共行动；
- 只有具备关系、达到非儿童阶段且造成足够影响的人，才能成为历史焦点；
- 新生人物采用普通姓名而非永久的“新生儿”占位名称。

## 后果

世界获得可追溯的人物传承链。婚姻、家庭制度、收养、跨城亲缘与遗产继承仍将在后续扩展。
