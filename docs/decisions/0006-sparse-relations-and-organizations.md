# ADR-0006：采用稀疏关系网络与组织驱动的社会模拟

状态：接受  
日期：2026-09-06

## 决定

- 每位独立人物只维护少量本地关系，而不与全体人物两两建边；
- 关系包含类型、信任、恩债、恐惧、誓言与最近互动年份；
- 人物行动只改变已知且同区域的关系，从而让千人模拟保持线性规模；
- 城邦、神殿、民兵、学社、商盟、葬仪团与逐火传播团作为首批组织；
- 组织通过成员、领袖、目的、地区与影响力连接人物行动和城邦历史；
- 缇里西庇俄丝在默认起点领导逐火传播团，传播团可招募本地高共鸣者。

## 后果

人物成为历史焦点时，系统可以说明其社会关系、组织归属和具体行动，而非只给出抽象影响力数值。家庭、跨区域组织、政治派系、背叛与复杂誓言仍是后续工作。
