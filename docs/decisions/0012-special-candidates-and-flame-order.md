# ADR-0012：以昔涟与白厄原型构成稀有候选与逐火归还顺序

状态：接受  
日期：2026-09-10

## 背景

十二火种不能被建模为同概率、可任意排序的收集品。项目需要使岁月与负世分别承担“见证旧世界”与“承载旧世界”的不可替代位置，同时让绝大多数世界保留无法走向再创世的可能。

## 决定

1. 将其余十位黄金裔视为常规逐火候选：他们能由人物属性、关系、危机和试炼在单次世界中相对自然地产生；
2. 将欧洛尼斯候选定义为“无暇之灵魂”、刻法勒候选定义为“完美之容器”；二者是跨世界线都罕见的特殊候选；
3. 两位特殊候选都需要对应因子达到极高值，并通过独立稀有候选判定；单次世界不保证产生任何一位；
4. 岁月火种固定为倒数第二枚归还。候选人必须见证其余十枚火种的归还与相关人物故事；
5. 岁月归还后，负世持有者作为最后持有者承担全部火种与旧世界，完成再创世。

## 后果

- 大多数模拟会因缺少其中一人、无法完成十枚火种归还，或人物选择不同而走向衰亡；
- 逐火过程具备明确但不机械的叙事高潮：十人留下故事，岁月保存故事，负世背负故事；
- 实现必须把“特殊候选是否存在”与“普通人物是否成为黄金裔”分开建模，且必须在界面和历史中可追溯；
- 跨世界线检索的具体交互与概率模型尚未决定，不在本 ADR 中实现。
