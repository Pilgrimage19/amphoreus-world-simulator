# ADR-0010：以神权、人格与因果生成半神的有意义终局

状态：接受  
日期：2026-09-06

## 背景

原作黄金裔的死亡并非单一的“持火种即献祭”流程：有人为同伴牺牲、有人守护领地、有人为真相殉身、有人被循环与夺火扭曲。若沙盒把半神的死亡写成固定倒计时，会同时失去自由度、人物性与情感重量。

## 决定

1. 半神不因普通年龄上限而自然死亡；其死亡必须由可追溯的世界事件、神权代价、冲突或自主抉择导致；
2. 每枚泰坦火种在正式实现前，必须定义一套**特殊神权**：能改变什么、守护什么、滥用或长期使用的代价、危机中可作出的牺牲；
3. 人物不会因“某个因子高”而被脚本指定死亡。神权只生成困境与可行动作，最终倾向由因子、关系、组织责任、记忆、既往伤害与随机环境共同决定；
4. 半神终局可包括守护至死、以火种封印或净化、为再创世献祭、在夺火中死亡、失控后被阻止、交出神权后以凡人身份延续等；
5. 系统必须记录“为什么此人走向这一结局”：触发危机、可选方案、选择依据、受影响的人与世界后果。

## 神权设计模板

每个泰坦至少应有：

```text
神权效果：它在世界中能实际改变什么？
守护对象：它优先庇护人、城邦、秩序、记忆、自然，还是某种价值？
持续代价：使用它消耗什么，或把什么风险转嫁给谁？
终局抉择：在不可两全的危机中，持有者可以牺牲什么？
人格诱因：哪些因子、关系和经历会让人物偏向不同选择？
```

## 后果

- 火种继承后不只增加数值，而会改变世界和持有者面临的道德问题；
- 相同火种由不同人物继承，应能产生不同的守护方式与死亡方式；
- “伟大的死亡”只能是可能结果，不能是对玩家或模拟的强迫剧本。
