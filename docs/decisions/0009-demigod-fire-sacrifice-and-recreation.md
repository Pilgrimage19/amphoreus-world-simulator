# ADR-0009：半神、火种献祭与再创世终局

状态：接受（终局方向）；部分机制待定  
日期：2026-09-06

## 背景

火种继承若只是给人物增加能力，会把黄金裔变成普通的长寿升级角色，也无法形成翁法罗斯式的“守护—牺牲—再创世”张力。项目需要让半神的生命、火种归属与消除黑潮的终局处于同一条因果链。

## 决定

1. 承接至少一枚泰坦火种、成为半神的人物不再因普通年龄上限自然死亡；
2. 半神仍可因黑潮、冲突、夺火、献祭或其他明确世界事件死亡；
3. 半神的长期道路至少包含两种可涌现选择：
   - 守护：以火种与自身行动维持领地、人民或某种世界秩序；
   - 献祭：将火种连同半神自身归还到再创世进程中；
4. 火种可被争夺。夺取导致原持有半神死亡，或在后续另行定义的极端条件下失去半神身份；
5. “所有必要火种最终被献祭，由背负世界之人完成再创世、消除黑潮”是默认的最高终局方向；它不是开局即锁定的结局，必须由世界状态与人物选择共同达到；
6. 火种献祭不是普通按钮，也不能由单一属性门槛完成；需要仪式地点、世界条件、组织/人物行动与明确代价。

## 尚未决定

- 火种献祭的直接目的、每一枚火种在再创世中的精确功能；
- “背负世界之人”的产生、资格与是否可以多人竞争；
- 被夺火时是否必然死亡，或是否保留极罕见的无火存活分支；
- 再创世是否总能彻底消除黑潮，或可能产生带遗产的新世界。

## 实现约束

- 在这一 ADR 实现前，当前原型中的“半神也会在 78 岁死亡”必须视作临时缺口，不能当作正式设定；
- 人物历史档案必须保存半神的守护、献祭、夺火和死亡因果，不能因其死亡从历史中消失；
- 再创世资格的计数必须按火种本身，而非按持火种的人数计算。
