# ADR-0004：采用“正史起始世界，涌现式终局”

日期：2026-09-05  
状态：接受

## 背景

项目希望充分使用翁法罗斯的世界设定、泰坦、城邦、黑潮、火种与轮回概念，但不能把原作主线或永劫回归固定为每局的预定脚本。

## 决定

游戏默认采用“正史起始世界”：以原作中不依赖开拓者干预的世界结构、地理、泰坦关系、城邦状态和灾难压力作为开局条件。

游戏不默认启动白厄/昔涟式的永劫回归，也不强制原作人物达成固定结局。永劫回归必须是由世界状态、人物动机、权柄组合与玩家干预共同产生的可能终局之一。

## 永劫回归的生成条件

一个世界只有同时满足以下条件时，才可能形成“同一世界被重复重置”的永劫回归：

1. 世界面临不可接受的终局；
2. 存在拥有时间、记忆、门径或同类权柄的行动者；
3. 行动者知道或推断出常规再创世无法接受；
4. 行动者愿意支付重置的代价；
5. 存在能跨重置保留的锚点，例如记忆、誓言、火种碎片或世界状态；
6. 重置机制没有被其他权柄、城邦或人物阻止。

这会允许世界产生“永劫回归”，但也可能产生正常再创世、有限继承、文明灭绝、权柄碎裂、泰坦共存或其他未预写终局。

## 后果

- 原作设定成为初始条件，而不是剧情强制器；
- 原作人物可作为高权重历史原型，但不拥有不可违背的命运；
- 需要将正常再创世与永劫回归建模为不同机制；
- 需要为跨轮回记忆、代价、锚点和重置失败设计可观察的因果链；
- “正史循环模式”若未来存在，应作为独立的可选情景，而非默认玩法。
