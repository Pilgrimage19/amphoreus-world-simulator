# ADR-0005：以十二因子驱动个体与权柄继承

状态：接受  
日期：2026-09-05

## 背景

翁法罗斯的十二因子应理解为十二种生命原动力的简化模型。若将它们误做十二个固定角色、职业或单一数值门槛，世界会退化为预写角色表，无法产生用户要求的自由度、随机性和未知终局。

## 决定

1. 十二因子作为每个个体、组织和城邦的一组可变化底层倾向存在；
2. 因子不直接命令行动，而是改变欲望、恐惧、价值判断与候选行动权重；
3. 黄金裔是涌现身份：角色须对某因子形成高且稳定的共鸣，并通过可追溯的经历与选择加以显现；
4. 泰坦火种/权柄继承须同时评估：因子共鸣、行为与经历、火种状态、外部条件、继承代价；
5. 继承可失败、拒绝、被争夺或产生多权柄冲突；原作黄金裔仅是正史起始世界的高共鸣实例，并非永久锁定的唯一继承者。

## 后果

### 正面

- 世界可产生原作未预料的新黄金裔、错位继承和不同终局；
- 角色的行动能从可解释状态推导，而非依赖大模型临场编造；
- 继承权柄自然成为有代价、有因果链的叙事高潮。

### 代价与约束

- 需要为因子变化、共鸣稳定性、资格判定与权柄冲突建立可测试的规则；
- 不能把“高数值”误写成“必然善/恶”或“必然继承”；
- 十二因子的正式原作词表和一对一映射仍需逐项考据并标注事实等级。
