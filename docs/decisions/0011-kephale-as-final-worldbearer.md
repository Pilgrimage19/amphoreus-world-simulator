# ADR-0011：以刻法勒火种持有者作为再创世的最终负世者

状态：接受  
日期：2026-09-09

## 背景

逐火系统需要避免把十二枚火种处理成可任意收集的等价物。项目已确认十二因子与十二泰坦的映射，并建立了地区信仰和人物泰坦关系；下一步需要确定再创世的最终承载结构。

## 决定

1. 确认十二因子与十二泰坦的当前映射，作为候选、试炼与神权设计的基础；
2. 人物对泰坦的虔诚、怀疑、爱、恨或反抗都可成为试炼入口；信仰不是取得火种的唯一资格；
3. 刻法勒的火种不作为与其他火种完全对称的早期收集物。其继承者是“负世者”候选；
4. 当其余必要火种均已归还创世涡心后，刻法勒火种继承者承担全部火种，背负旧世界并完成再创世；
5. 各泰坦的具体权能、试炼内容、使用代价、献祭条件与献祭效果仍处于待审核状态，不在本决定中固化。

## 后果

- 逐火的中后期将自然产生“谁有资格成为负世者”的世界级问题；
- 刻法勒候选必须满足比普通火种继承更高的综合条件：承担能力、人格品质、人生痕迹、组织认可与其他火种的相容性；
- 再创世不是简单的十二火种计数完成，而是“火种归还”与“负世者承担”两个阶段都完成。
