# ADR-0008：采用生命周期社会化维持代际网络

状态：接受  
日期：2026-09-06

## 背景

只有亲属继承不足以维持数百年社会：后一代若不建立同龄关系与伴侣关系，就无法成为新的家庭和组织起点，人口及历史网络会断裂。

## 决定

- 青年与成年人可以在同区域内形成稀疏的新关系；
- 青年优先形成同窗关系，成年人形成友人、同业、同行者或伴侣关系；
- 伴侣关系要求年龄阶段、社会性、同谐倾向与随机机遇共同满足；
- 禁止共享父母的亲属配对；
- 家庭产生继续依赖稳定双向关系，而非由抽象人口数直接生成。

## 后果

第二代以后能自行形成家庭、组织和新的历史人物。婚姻制度、性别、生育意愿、收养、地域习俗及跨区伴侣仍未建模。
