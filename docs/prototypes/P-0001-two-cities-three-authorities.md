# P-0001：双城与三权柄

状态：可手工执行的规则草案 0.1  
记录日期：2026-09-04  
目标：验证一组小规则能否产生可解释、可跨轮回继承的不同历史。

## 0. 原型边界

- 20回合；每回合代表一个“季”；
- 两座城邦，人口以“户”为单位；
- 六名关键人物，普通人口不逐人模拟；
- 三项开发代号权柄：天时、纷争、律法；
- 一种末日威胁：黑潮；
- 一次轮回结算；
- 不使用大模型，不加入预写剧情分支。

## 1. 初始世界

北：风暴高地（天时权柄遗迹）
中：曙光河谷（两城共享的粮食与道路）
南：雾海裂隙（黑潮源头，律法碑残片）

### 权柄状态

| 权柄 | 载体 | 人格倾向 | 当前效果 | 失控阈值 |
|---|---|---|---|---|
| 天时 | 风暴高地祭器 | 反复无常 | 每回合改变丰收/风暴修正 | 持有者死亡或祭器损坏 |
| 纷争 | 悬锋巨剑 | 崇尚胜者 | 军备高的一方更易将冲突升级 | 流血事件累计3次 |
| 律法 | 裂隙碑残片 | 只承认誓言 | 誓言被履行时秩序+2；违背时秩序-2 | 无人维护或碑被黑潮吞没 |

### 黑潮

初始强度：2 / 10。强度达到6时，裂隙邻接地区减产；达到8时，每回合一个城邦必须损失人口或秩序；达到10时进入轮回结算。

## 2. 每回合结算顺序

1. 天时：掷天时骰，得到丰收、平稳或风暴；
2. 生产：每城粮食 `+2 + 天时修正 - 黑潮惩罚`；
3. 生存：粮食不足则人口-1、秩序-1；
4. 城邦计划：根据需求、关系和人物影响选择贸易、修筑、索取、进攻或援助；
5. 人物计划：关键人物可结盟、履行/违背誓言、远行、夺取/守护权柄；
6. 冲突解决：先记录双方意图，再按军备、秩序、人物与权柄修正结算；
7. 黑潮：若裂隙未被压制，强度+1；若有封印行动则按代价降低；
8. 事件记录：为每个非平凡结果写入原因、见证者和后果；
9. 终态检查：黑潮≥10、两城皆亡、轮回被打破或第20回合结束。

## 3. 随机表（可复现手工版）

使用一颗六面骰；正式实现改用隔离的伪随机流。

| 骰值 | 天时 | 城邦压力 | 人物转折 |
|---:|---|---|---|
| 1 | 风暴：粮食-2 | 恐慌：秩序-1 | 恐惧加重 |
| 2 | 阴雨：粮食-1 | 紧张 | 旧伤复发 |
| 3 | 平稳 | 平稳 | 无额外修正 |
| 4 | 平稳 | 机会 | 关系加深 |
| 5 | 丰收：粮食+1 | 野心 | 发现线索 |
| 6 | 晴朗：粮食+2 | 团结 | 誓言得到回应 |

随机表只提供扰动。最终行动应由当前状态解释，不能因为骰子要求角色无理由背叛。

## 4. 城邦决策规则

每城计算五项候选行动的权重，选择最高者；相同则掷骰。

```text
贸易 = 粮食压力 × 2 + 关系 + 律法秩序
修筑 = 黑潮强度 × 2 + 秩序
索取 = 粮食压力 + 军备差 + 不信任
进攻 = 军备差 + 纷争压力 + 野心 - 关系 - 黑潮强度
援助 = 黑潮强度 + 关系 + 誓言影响 - 粮食压力
```

变量可先取0～3的离散档位。每次选择都要把各权重写进事件记录，以测试“可解释性”。

## 5. 三条应出现但不应强制出现的历史走向

### 走向A：共同封印

黑潮加剧 → 两城粮食恶化 → 信使与旧约促成合作 → 守望者履行誓言守住裂隙 → 记史者保存牺牲真相 → 黑潮下降，城市存续。

遗产候选：封印碑、塞芙的誓言、共同治理制度。

### 走向B：胜利者的空城

悬锋借纷争权柄击败奥赫 → 获得河谷资源 → 黑潮无人压制 → 高秩序但人口凋零的统一城邦无法抵抗末日。

遗产候选：巨剑、被篡改的史书、逃亡者血脉。

### 走向C：以律法换取轮回外的记忆

城邦无法封印黑潮 → 伊娅和阿刻改写残碑条文 → 以一座城的遗忘换取记忆残响 → 世界进入轮回，但下一世某些人物会梦见河谷。

遗产候选：残碑、无名英雄传说、梦境记忆。

## 7. 轮回结算

### 终态向量

```text
世界：存续 / 毁灭 / 受控重置 / 打破轮回
文明：双城 / 统一 / 流亡 / 灭绝
天时：稳定 / 失控 / 无主
纷争：封存 / 被继承 / 失控
律法：被守护 / 被篡改 / 消失
人物：存活、死亡、牺牲、被遗忘、成为传说
记忆：完整、扭曲、残响、断绝
```

### 遗产选择

从下列候选中最多保留3项，每项都应有负面或机会成本：

- 一件物质遗产；
- 一条血脉或群体特性；
- 一部文化遗产；
- 一枚人物记忆残响；
- 一份未完成的誓言；
- 一个不稳定权柄碎片。

## 8. 评估问题

原型运行三次后回答：

1. 三局的历史是否真的不同，还是只改了数值？
2. 是否至少有一次人物关系改变了城邦行为？
3. 是否至少有一次权柄改变了“规则”而非战力？
4. 是否能从任一终态逆推三步以上原因链？
5. 第二世是否能因遗产而出现不同决策空间？
6. 哪个规则总是压倒其他规则？哪个永远没有影响？

若任一问题答案为否，先改规则，不进入客户端开发。
