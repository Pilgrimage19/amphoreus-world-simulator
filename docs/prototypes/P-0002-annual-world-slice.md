# P-0002：年度世界模拟纵切

状态：已实现，待平衡  
日期：2026-09-05

## 目的

验证“年度尺度 + 区域网络 + 十二因子 + 千名独立人物”能否作为项目基础，而不预先指定关键人物名单。

## 已实现

- 一回合为一年；
- 奥赫玛、雅努萨波利斯、悬锋城、神悟树庭、斯缇科西亚、哀地里亚、高天遗迹七个区域；
- 十二泰坦的数据模型：分组、司掌、因子、领地、稳定度、腐化与火种持有者；
- 每位独立人物具备十二因子、基础能力、年龄、健康、饥饿、地区、影响力、共鸣年数与黄金裔状态；
- 缇里西庇俄丝作为“已取得门径火种的第一位半神”这一情景锚点；
- 人物按局部状态选择工作、援助、组织、研究、寻求权柄、迁徙或冲突；
- 黑潮按区域扩散，影响资源、健康与迁徙；
- 高影响人物自动进入历史焦点；高且稳定的因子共鸣可使普通人物成为黄金裔候选；
- 输出仅保留最多 30 名历史焦点，避免千人存档界面失控。
- 每人持有 4～8 条初始本地关系，关系会随援助、组织、逃离与冲突变化；
- 建立七类初始组织，逐火传播团由缇里西庇俄丝领导并可招募成员；
- 本地网页可点击历史焦点人物，查看其关系、誓言与组织。
- 新生人物由具稳定关系的成年双亲产生，继承因子倾向、亲属关系与部分家庭社会联系；
- 人物区分儿童、青年、成人与长者，儿童不累积公共影响力。
- 按区域文化生成个人名与家系名；姓名素材为项目原创，内部唯一 ID 不受重名影响，后代优先继承父母家系名。
- 青年与成年人会建立同窗、友人、同业、同行者或伴侣等新关系；伴侣关系支持跨代家庭延续并规避近亲配对。
- 每个区域拥有独立于精细模拟人物的总人口；约千名独立人物是可被追踪的代表样本，而非世界全部人口。

## 有意简化

- 泰坦中只有刻法勒、瑟希斯、塔兰顿、雅努斯具有首批可见的年度效果；其余泰坦目前是完整数据而非完整规则；
- 婚姻制度、收养、跨区域亲缘、家庭财产、精确人口统计、城市政治、火种试炼和神战尚未实现；
- 出生与死亡是人口连续性的粗粒度机制，尚未代表真实家庭或翁法罗斯社会；
- 只有门径火种在初始时被持有；其他火种的取得与继承尚未实现；
- “再创世资格”只是接口，不会重置或生成下一代世界。

## 下一阶段

先实现人物关系与组织，再实现火种试炼。二者会决定“高共鸣”是否真正成为可解释的黄金裔，而不是单纯数值晋升。

## 本地观察面板

可运行无第三方依赖的本地网页观察面板。它显示年度、地区居民总数、独立人物样本、区域资源/秩序/黑潮、组织、事件、历史焦点人物和十二泰坦，并可推进一年或重置同一种子世界。

```powershell
$env:PYTHONPATH = 'src'; python -m amphoreus_sim.web --seed 42
```

启动后访问 `http://127.0.0.1:8000`。面板仅监听本机，不向互联网发送数据。可推进一年或连续推进十年。
