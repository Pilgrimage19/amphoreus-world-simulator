# 项目交接：翁法罗斯世界模拟器

更新时间：2026-10-03
交接用途：供下一段 Codex 对话直接继续设计与实现。

## 1. 项目目标与边界

这是一个开源、非商业的 Python 原型项目，路径为 `D:\desktop\amphoreus-world-simulator`。目标不是复刻《崩坏：星穹铁道》剧情，而是以翁法罗斯的**不依赖开拓者干预**的世界底层设定作为沙盒起始条件，生成可复现、可解释、可能出现设计者未预料结局的文明历史。

- 每回合为 1 年；
- 以确定性规则、属性、关系、资源、组织、地区、泰坦和黑潮共同产生随机性；同一随机种子应复现同一历史；
- 大模型未来最多用于叙事解释，不拥有世界状态写权限，也不作为主要随机源；
- 画质不是当前目标；网页仅为观察面板，未来才考虑世界盒子式交互；
- 默认起点是缇里西庇俄丝传播“人可逐火”后的早期逐火时代；十二泰坦已存在，但黄金裔不预设为原作人物或固定登场顺序；
- 开拓者到来只能是后续可选外来变量，不能写入默认历史。

## 2. 当前可运行内容

核心已经是一个 Python 年度模拟器，具有：

- 7 个初始地区、12 泰坦、地区主领地泰坦与可变的多泰坦信仰；
- 黑潮、资源、地区失陷、难民、避难容量、组织、人口和长期“劫余”衰亡；
- 宏观人口与独立人物样本严格关联，人物不会超过总人口；
- 人物属性、关系、历史影响力、焦点人物筛选、中文随机姓名；
- 多年黑潮/难民危机，以及网页中的世界总览、地区、人物、泰坦、历史视图；
- 网页人物只展示十二因子中各自走得最远的一位有意义人物；在世与已故行者合计最多 12 人，完整档案仍保留在快照数据中；
- 半神不因年龄、普通伤病、饥饿或通用人口缩减机制无意义死亡；
- 未能再创世时，世界通过劫余、黑潮和孤城负荷最终连锁崩溃，而非固定倒计时；高黑潮会压低出生、加快死亡，低于城邦最低维持规模的孤城会累积更快的失陷压力。当前十二火种版三种子寿命已延长至 1287–1483 年，不能再沿用早期“数百年”的平衡结论；
- 城邦失陷后成为“残存区”，居民会撤离或消亡，不能继续作为正常生产、出生、补充样本、组织或火种试炼的来源。

十二火种的专属试炼、权能与归还条件均已接入；旧的死亡/纷争通用试炼已移除。现行参数以 `docs/prototypes/P-0004-complete-flamechase-and-story-links.md` 为准。新增结构化逐火史，岁月消费真实归还故事，负世消费十一枚印记；`recreation_ready` 是准备完成终局，尚未实现下一代世界生成。

## 3. 已确认的设定与设计决定

### 3.1 十二泰坦、因子与地区

| --- | --- |
| 艾格勒 | 天空 / 存护 |
| 吉奥里亚 | 大地 / 不朽 |
| 法古萨 | 海洋 / 虚无 |
| 欧洛尼斯 | 岁月 / 记忆 |
| 塔兰顿 | 律法 / 秩序 |
| 雅努斯 | 门径 / 同谐 |
| 墨涅塔 | 浪漫 / 纯美 |
| 刻法勒 | 负世 / 毁灭 |
| 瑟希斯 | 理性 / 智识 |

| 尼卡多利 | 纷争 / 巡猎 |
| 塞纳托斯 | 死亡 / 均衡 |

泰坦关系不是单一信仰值：人物可虔诚、爱、恨、怀疑或反抗某泰坦。试炼资格须综合非中立关系、因子、能力、人格、人生痕迹和真实危机选择。

### 3.2 逐火终局的总体顺序

1. 十位常规黄金裔可由世界事件和人物自然涌现；
2. 欧洛尼斯候选“无暇之灵魂”和刻法勒候选“完美之容器”是跨世界线都极罕见的特殊候选；二者均需对应因子极高，加独立稀有候选判定。单次世界不保证出现；
3. 十枚常规火种先归还创世涡心；
4. 岁月火种固定为倒数第二枚。无暇之灵魂必须见证前十枚火种归还及其人物故事，才可归还岁月火种；
5. 完美之容器最后承接全部火种与旧世界，完成再创世。大多数世界应因缺少特殊候选、火种未齐或人物选择不同而无法抵达此结局。

### 3.3 已审核通过的个别泰坦方案

历史审核表见 P-0003，现行参数见 P-0004；全部十二位已接入原型。用户 2026-10-03 明确授权直接修复、设计和调整未指定的规则，覆盖此前逐项先审的开发暂停流程：

- **门径（已实现）**：传播逐火思想；拥有 5 次永久救援额度，只将道路断绝、尚未承接火种的黄金裔候选送回仍未失陷的奥赫玛；人物层救援不受奥赫玛宏观人口容量阻塞，也不对半神消耗额度；额度耗尽自动献祭，火种归还；
- **天空（已实现）**：唯一硬性血脉试炼；人物保存不会随迁徙改变的出生地，高天遗迹出生者获得存护主导倾向，作为艾格勒血脉的当前替代。候选须先成为存护黄金裔，在黑潮至少 25 的地区以救援、组织或撤离行动五次维持避难通道，并亲历高天遗迹失陷；承接后每年预警并加固当前最危险的未失陷城邦，严重风暴会累积负担。奥赫玛首次进入不可逆失陷时，持有者献祭并归还火种，降低黑潮及残留源、恢复粮食/秩序/防线并取消该次坠落；此后奥赫玛仍会继续接受通用失陷规则；
- **大地（已实现）**：守土者试炼；所有以不朽为最高因子的成年黄金裔都会受召，但只有所在地黑潮至少 50、或黑潮至少 35 且社会紧张至少 50、或避难超载时，才能在同一尚未失陷的地区累计 5 年守土。持有者恢复粮食、工事、黑潮与伤痕并绑定土地。承接后至少实际持有 5 年；此后若除奥赫玛外至少五座城邦失陷且奥赫玛仍存，持有者才献祭，在其附近建立容量 8,000 的“磐生城”。建城当年会从奥赫玛迁入首批居民及对应独立人物，不再生成无人空城；随后持有者死亡并归还火种；
- **海洋（已实现）**：第 50 年后，共情不高于 35、虚无最高的成年黄金裔，在斯缇科西亚或其商盟实际流亡并保留引航传统的城邦，于黑潮至少 25 时完成五次引航。低共情资格在开始时校验，开始后理性培养不能取消已有试炼。承接后与首位非负世持火半神建立唯一羁绊，每三年开海路、迁入居民、运补并承担污染。只有锚点主动献祭才随祭，普通死亡不触发；若锚点为岁月，其他九枚已有真实归还记录后同一结算启动不可撤回献祭，海洋第十枚、岁月见证后第十一枚，避免互相等待；
- **死亡（已实现）**：从存活成年、均衡最高的黄金裔中，仅按死亡因子选最高者；同分保留受召者，三次厄运后须双向信任及半神/渡厄之心资格的主动羁绊。浪漫优先连接受召者；远方半神沿道路赴约，见面才通过，不能让大地绑定者离土。承接后在冥界引渡已登记亡者，不参与凡人日常；持有五年且总人口降至初始十分之一（下限一千）后献祭；
- **纷争（已实现）**：第 50 年后每五年正面挑战，勇气至少 60、体魄至少 55，胜率 3%–30%，失败即死亡。承接后在失陷城邦行旅，从实际存续城邦迁入志愿者创建最多三处余烬营地；旧城不复活、人口守恒。至少二十行旅年后才承受逐步增长的专属战死风险，阵亡时归还；
- **律法（已实现）**：候选在危机中立律并守律五次；承接后改善秩序、累积刚性，每五年进行危机公开裁断。至少持有二十年、完成三次裁断、已有两枚其他火种归还后，放弃特权献祭。旧“等十枚归还”造成与岁月循环依赖，已经移除；
- **浪漫（已实现）**：真实负担中与三位不同对象建立双方信任至少 55 的关系，不能反复计入同一对象。承接后连接当地陌生幸存者，每五年以金线额外连接两位未相识的黄金裔/半神，降低紧张并积累情感负担。五城失陷、织结六次且仍有珍贵关系时献祭归还；
- **理性（已实现）**：智识最高的成年黄金裔参加“瑟希斯四证”（辨真、演绎、衡世、择未来），考试不随机淘汰；智识因子与洞察越高，单门耗时按指数曲线由 20 年缩短至 5 年。持有者提升现有黄金裔的体魄、洞察、社交、领导及候选人特质；每当受培养的黄金裔通过自身火种试炼成为半神，即记为一名成果。培养出第三名半神后权能耗尽，持有者死亡并归还火种；
- **诡计（已实现）**：保留制造面具、揭露阴谋、坦白最大谎言的试炼。承接后以被相信的谎言有限维持奥赫玛黎明，承担面具、社交和信任代价；揭密为辅助权能。至少持有五十年且五城失陷或天空已治愈时，将秘密交给活着的后继黄金裔/半神并献祭。旧“揭密五次即归还”已替换；
- **岁月（已实现）**：记忆最高人物创建时进行一次 1/4000 极高因子尾部判定，再以独立 1/4 判定产生无暇之灵魂；须先觉醒黄金裔，再在三段承接故事存在时完成十五年忆页三问。承接后保存真实归还事件和记忆负担；十常规全部归还且十段故事均已见证，才倒数第二归还；
- **负世（已实现）**：毁灭最高人物采用同样一次性的两阶段稀有判定，先成为黄金裔。至少五枚常规已经承接/归还，且在真实危机十次承担，才承接负世。持有期间有限保护幸存避难所，每三年接纳一枚实际归还的火种印记；岁月归还、十一印记接纳且容器仍活着，才进入再创世准备终局。

## 5. 环境与运行命令

只能使用用户指定的 Conda 环境 `amphoreus-world-simulator`：

```powershell
$env:PYTHONPATH = 'src'
conda run --no-capture-output -n amphoreus-world-simulator python -m unittest discover -s tests -v
```

启动网页：

```powershell
$env:PYTHONPATH = 'src'
conda run --no-capture-output -n amphoreus-world-simulator python -m amphoreus_sim.web --seed 42
```

浏览器地址：`http://127.0.0.1:8000`。改动服务端或前端后，需要停止旧服务、重新启动，并在浏览器中使用 Ctrl+F5 刷新。

`D:\miniconda\miniconda3\envs\amphoreus-world-simulator\python.exe`。

## 6. 已发现的问题、失败尝试与注意事项

- **网页结束状态已修复**：`WorldServer` 会持久记录 EndingKind 与结局摘要；所有城邦失陷等结局触发后，网页停止推进并禁用按钮，重置会清空该状态。
- **网页端已完成专项加固**：HTTP JSON 请求会校验对象、长度及 `years`/`seed` 类型，错误请求返回结构化 400/413 且不改变世界；人物详情读取与推进/重置共用锁；前端同一时间只允许一个世界操作，人物详情会随推进刷新并在重置时清空。专项加固时曾以种子 42 第 941 年旧规则终局验证推进按钮保持禁用；当前终局年份已随新增逐火模块变化。
- **运行中的旧世界不会应用代码修复**：网页若没重启/重置，已经死亡的半神、旧容量等历史不会倒转。用户此前看到半神在旧存档中因普通健康逻辑死亡；代码后已针对新世界修复半神的普通死亡，但旧世界不恢复。
- **失陷城邦仍有居民的问题已处理**：现为残存区，居民撤离或递减，不再生产/出生/生成普通样本。半神能停留以等待专属事件。
- **人口/独立人物不一致的问题已处理**：独立人物是宏观人口观察样本，不是额外人口；随人口缩减而减少。
- **奥赫玛容量无上限的问题已处理**：新增 `refuge_capacity_limit`，只有特定安置路线增长容量。但平衡仍需未来重新测量。
- **高黑潮低人口平衡已修复**：高黑潮会压低出生率、以二次曲线提高死亡率；人口跌破避难容量 1%（至少 100 人）且黑潮至少 50 时，秩序或粮食失效会使城邦在两年内进入失陷。仅余两孤城时还会损失守备、累积黑潮源。接入当前逐火代码后，种子 42 从头回放在第 512 年全城邦失陷。
- **黄金裔出现率**：当前门槛为主导因子至少 68、连续共鸣 2 年、个人影响至少 5；因子仍是出生/遗传属性，后天不直接增长。种子 42 完整回放为 4,260 / 13,365 名曾生成独立人物（31.9%）成为黄金裔或半神，符合约三成目标；半神数量与十二条试炼的平衡仍须在后续逐火实现后重新多种子测量。
- **候选人属性基础层**：已加入勇气、共情、意志、克制、野心、适应力，以及可累积的人生痕迹（守护、失去、誓言、背叛、责任、胜利后的选择、黑潮侵蚀、重大组织行为）。目前守护/组织会累积责任，责任直接降低黄金裔逃离权重；其余痕迹将随各泰坦专属试炼逐步接入。
- **已实现火种的最新约束**：黄金裔只能以其最高因子对应的泰坦进入半神试炼；门径仅在黄金裔于黑潮至少 50 的地区尝试逃离却找不到正常安全路线时开启；安全路线须未失陷、黑潮低于 50、且收容未达九成，故门径不替代正常迁徙；大地候选会留在尚未失陷的故土守土。种子 42 跑至第 800 年已成功出现过大地半神与火种归还；门径在此改动后仍需重测自然触发次数。
- **迁徙统一规则**：宏观居民、独立人物和失陷区残存者均在来源黑潮至少 50 后才会撤离，目的地必须满足同一安全路线标准；这避免独立人物与宏观人口对失陷城邦或高黑潮城市作出相互矛盾的迁徙判断。
- **组织流亡与传统续接**：学社、商盟、葬仪团和逐火团若有真实幸存成员迁入存续地区，可迁址且影响力减半；无幸存者仍消亡。海洋试炼可跟随斯缇科西亚商盟的真实流亡继续开展，避免港口失陷便永久断绝候选来源。
- **最新平衡调整**：门径救援额度最终定为 5 次；所有以不朽为最高因子的成年黄金裔都能进入大地守土链，体魄和大地立场改为影响守土表现而非候选资格；任何仍有居民、却低于城邦最低维持人口的城市都会累积失陷压力，不会因黑潮暂低而无限期停在极少人口。
- **大城失陷规则**：黑潮达到 40 且粮食或秩序已失效的城市，即使人口仍多，也会持续累积失陷压力；黑潮 45 以上时每年加速。这避免大城市因人数尚多而在社会结构已崩坏后无限期“稳定”。
- **失陷状态不可自行回生**：失陷城邦是终态；黑潮回落或人口归零不会让废墟重新变成正常城市。未来若加入复兴，必须通过显式重建事件创建或恢复，而非通用状态结算自动反转。
- **当前长程审计**：`python -m amphoreus_sim.audit --seeds 42 7 2026 --ticks 2000 --population 1000 --summary --output docs/audits/2026-10-03-final.json` 输出结局、人口、失陷顺序、十二火种旅程、逐火史和阻塞原因；每年校验状态不变量。三个种子分别在 1483 / 1410 / 1287 年崩溃，累计独立人物 29161 / 27941 / 25102，均出现十位常规持有者，归还 10 / 9 / 9 枚，异常均为 0。无特殊候选；成功终局只在专项构造测试中验证。证据与阶段说明见 `docs/audits/README.md`。
