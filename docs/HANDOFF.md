# 项目交接：翁法罗斯世界模拟器

更新时间：2026-09-10  
交接用途：供下一段 Codex 对话直接继续设计与实现。

## 1. 项目目标与边界

这是一个开源、非商业的 Python 原型项目，路径为 `D:\desktop\amphoreus-world-simulator`。目标不是复刻《崩坏：星穹铁道》剧情，而是以翁法罗斯的**不依赖开拓者干预**的世界底层设定作为沙盒起始条件，生成可复现、可解释、可能出现设计者未预料结局的文明历史。

- 每回合为 1 年；
- 以确定性规则、属性、关系、资源、组织、地区、泰坦和黑潮共同产生随机性；同一随机种子应复现同一历史；
- 大模型未来最多用于叙事解释，不拥有世界状态写权限，也不作为主要随机源；
- 画质不是当前目标；网页仅为观察面板，未来才考虑世界盒子式交互；
- 默认起点是缇里西庇俄丝传播“人可逐火”后的早期逐火时代；十二泰坦已存在，但黄金裔不预设为原作人物或固定登场顺序；
- 开拓者到来只能是后续可选外来变量，不能写入默认历史。

## 2. 当前可运行内容

核心已经是一个 Python 年度模拟器，具有：

- 7 个初始地区、12 泰坦、地区主领地泰坦与可变的多泰坦信仰；
- 黑潮、资源、地区失陷、难民、避难容量、组织、人口和长期“劫余”衰亡；
- 宏观人口与独立人物样本严格关联，人物不会超过总人口；
- 人物属性、关系、历史影响力、焦点人物筛选、中文随机姓名；
- 多年黑潮/难民危机，以及网页中的世界总览、地区、人物、泰坦、历史视图；
- 半神不因年龄、普通伤病、饥饿或通用人口缩减机制无意义死亡；
- 无逐火/再创世时，世界通过劫余、黑潮和孤城负荷通常在数百年（目标约 400–500 年）连锁崩溃，而非固定倒计时；
- 城邦失陷后成为“残存区”，居民会撤离或消亡，不能继续作为正常生产、出生、补充样本、组织或火种试炼的来源。

目前的火种/逐火系统尚未真正接入模拟；旧的简化核心火种试炼代码仍在，必须在按新设计重做前避免继续扩充。

## 3. 已确认的设定与设计决定

### 3.1 十二泰坦、因子与地区

当前映射：

| 泰坦 | 司掌 / 因子 |
| --- | --- |
| 艾格勒 | 天空 / 存护 |
| 吉奥里亚 | 大地 / 不朽 |
| 法古萨 | 海洋 / 虚无 |
| 欧洛尼斯 | 岁月 / 记忆 |
| 塔兰顿 | 律法 / 秩序 |
| 雅努斯 | 门径 / 同谐 |
| 墨涅塔 | 浪漫 / 纯美 |
| 刻法勒 | 负世 / 毁灭 |
| 瑟希斯 | 理性 / 智识 |
| 扎格列斯 | 诡计 / 欢愉 |
| 尼卡多利 | 纷争 / 巡猎 |
| 塞纳托斯 | 死亡 / 均衡 |

泰坦关系不是单一信仰值：人物可虔诚、爱、恨、怀疑或反抗某泰坦。试炼资格须综合非中立关系、因子、能力、人格、人生痕迹和真实危机选择。

### 3.2 逐火终局的总体顺序

1. 十位常规黄金裔可由世界事件和人物自然涌现；
2. 欧洛尼斯候选“无暇之灵魂”和刻法勒候选“完美之容器”是跨世界线都极罕见的特殊候选；二者均需对应因子极高，加独立稀有候选判定。单次世界不保证出现；
3. 十枚常规火种先归还创世涡心；
4. 岁月火种固定为倒数第二枚。无暇之灵魂必须见证前十枚火种归还及其人物故事，才可归还岁月火种；
5. 完美之容器最后承接全部火种与旧世界，完成再创世。大多数世界应因缺少特殊候选、火种未齐或人物选择不同而无法抵达此结局。

### 3.3 已审核通过的个别泰坦方案

完整权能表见 `docs/prototypes/P-0003-twelve-titan-authority-trials.md`。以下内容已确认，但尚未实现：

- **门径**：传播逐火思想；可将黑潮中濒死的黄金裔传回奥赫玛。每次救援永久消耗门径额度；额度耗尽自动献祭，火种归还；
- **天空**：唯一硬性血脉试炼；现阶段临时以“高天遗迹出身”代替艾格勒后裔。奥赫玛进入不可逆黑潮失陷时，持有者献祭自身发动一次天空治愈，阻止一次坠落；
- **大地**：守土者试炼，在灾荒中修复土地、维系聚落。终局以自身和火种扎根，在奥赫玛附近生成新城市基址，随后死亡归还火种；
- **海洋**：候选人低共情、感情淡薄；首次建立关系的非负世半神是唯一羁绊锚点。锚点主动献祭时，海洋持有者自动随之献祭；
- **死亡**：仅由死亡天赋最高者成为候选，周围人物会遭遇厄运；仍有人主动成为羁绊才通过。承接后引渡冥界亡魂；总人口低于待定阈值时自动献祭；
- **纷争**：唯一必须正面击败泰坦的火种，勇气驱动挑战、勇气和体魄决定胜率；失败即死亡且通过率最低。持有者游走失陷地区促成复兴，最终在黑潮行旅中阵亡；
- **律法**：受自身之法审判，建立且服从规则；终局废弃个人特权与例外；
- **浪漫**：为他人编织关系而非占有；终局将最珍贵的情感与关系织入火种；
- **理性**：证明再创世值得发生；拒绝把人当材料，封存可被少数人垄断或牺牲多数人的旧世界模型；
- **诡计**：最后的谎言；主动坦白最大谎言，交出面具与秘密，清除伪神和错误分支；
- **岁月**：只确认其特殊候选身份、倒数第二归还和见证十火种故事；具体试炼、权能、持续代价尚未设计；
- **负世**：只确认完美容器、最后承载全部火种并再创世；具体试炼与权能仍需要细化。

## 5. 环境与运行命令

只能使用用户指定的 Conda 环境 `amphoreus-world-simulator`：

```powershell
$env:PYTHONPATH = 'src'
conda run --no-capture-output -n amphoreus-world-simulator python -m unittest discover -s tests -v
```

启动网页：

```powershell
$env:PYTHONPATH = 'src'
conda run --no-capture-output -n amphoreus-world-simulator python -m amphoreus_sim.web --seed 42
```

浏览器地址：`http://127.0.0.1:8000`。改动服务端或前端后，需要停止旧服务、重新启动，并在浏览器中使用 Ctrl+F5 刷新。

Python 版本是 3.12.14，解释器为：
`D:\miniconda\miniconda3\envs\amphoreus-world-simulator\python.exe`。

## 6. 已发现的问题、失败尝试与注意事项

- **网页结束状态缺陷**：`web.py` 的快照 `ended` 目前只依赖总人口是否为 0；但模拟的“所有城邦失陷”等 EndingKind 没有被 Web 服务器持久记录，网页仍可继续推进到很后面。这是未修复的重要问题。建议给 `WorldServer` 增加 `ended` 和 `ending_summary`，`advance()` 接住 `Simulation.step()` 返回的结束结果并停止后续推进；重置时清空它；快照和按钮据此展示。
- **运行中的旧世界不会应用代码修复**：网页若没重启/重置，已经死亡的半神、旧容量等历史不会倒转。用户此前看到半神在旧存档中因普通健康逻辑死亡；代码后已针对新世界修复半神的普通死亡，但旧世界不恢复。
- **失陷城邦仍有居民的问题已处理**：现为残存区，居民撤离或递减，不再生产/出生/生成普通样本。半神能停留以等待专属事件。
- **人口/独立人物不一致的问题已处理**：独立人物是宏观人口观察样本，不是额外人口；随人口缩减而减少。
- **奥赫玛容量无上限的问题已处理**：新增 `refuge_capacity_limit`，只有特定安置路线增长容量。但平衡仍需未来重新测量。
- **黑潮曾无存在感、世界过于和平**：已加入长期劫余、孤城负荷等；无逐火的样例曾在约 486 年崩溃。该结果需要在接入逐火后重新做长程种子测试。
- **文档陈旧**：顶层 `README.md` 仍写“两城、三权柄”的早期第一目标，已不符合 7 地区/12 泰坦原型，未来应更新；不要将其当作当前架构真相。
- **版本控制状态**：最近检查时 `git status --short` 显示整个项目为未跟踪（`?? docs/`, `?? src/`, `?? tests/`, `?? README.md`, `?? pyproject.toml`, `.idea/` 等）。不要执行破坏性 Git 操作；如要提交，先与用户确认并检查仓库初始化/忽略规则。

## 7. 推荐的下一步

先不急于实现完整逐火。推荐顺序：

1. 修复网页对模拟结束状态的持久化和禁用推进，确保当前世界不会在应结束后继续跑；
2. 将 P-0003 中所有已审核方案拆成明确、可测试的数据结构：试炼资格、权能状态、使用代价、献祭触发器、世界效果；先完成字段与事件日志，不要一次性接入所有数值平衡；
3. 先实现一个端到端的最小逐火闭环（建议门径或大地）：候选产生 → 试炼 → 半神 → 权能 → 有意义献祭 → 火种归还 → 网页/历史可追溯；
4. 再实现“十常规候选 + 两特殊候选”的候选生成层，明确稀有候选是纯种子概率、世界线检索，还是二者混合；
5. 最后按泰坦逐个接入权能，持续以多种子 500–1000 年长程模拟进行平衡验证。

实现任何泰坦前，先将其 P-0003 待定项提交用户审核；用户明确要求设计先审、确认后保存/实现。
