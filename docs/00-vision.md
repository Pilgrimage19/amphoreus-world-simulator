# 项目愿景与边界

状态：草案 0.1  
最后更新：2026-09-04

## 一句话愿景

创造一个能够忠实表达翁法罗斯核心设定的开放世界模拟器：世界依照规则自行演化，玩家通过观察与有限干预，与跨越轮回的人物和历史建立感情。

## 三根设计支柱

### 1. 设定作为规则，而不是贴图

泰坦、权柄、火种、逐火和轮回必须真正改变模拟规则。泰坦不是高生命值单位；权柄不是技能名称；轮回不是普通清档。

### 2. 涌现历史，而不是穷举结局

系统记录事实和因果，结局由世界状态、文明形态、权柄归属、轮回状态及人物代价组合产生。设计者提供规则、约束与表达模板，不手写所有可能的结局。

### 3. 感动来自可追溯的关系

牺牲只有在玩家知道“谁为何牺牲、影响了谁、被谁记住”时才有意义。因此人物关系、记忆、誓言、传承和历史回看是核心系统，不是后期装饰。

## 玩家体验目标

玩家应能：

- 放慢时间，追踪一名普通人如何成为历史人物；
- 快进观察城邦、信仰和权柄的长期变化；
- 通过有限干预改变条件，但不能直接指定结局；
- 在轮回时选择少量遗产，并承担遗漏其他事物的代价；
- 点击任意重大结局，查看其关键原因链；
- 使用同一随机种子复现或分享一段历史。

## 明确不做

- 不以复刻原作战斗系统为目标；
- 不以高画质、3D演出或大量手工关卡为目标；
- 不让大模型决定世界事实或充当主要随机源；
- 不在早期模拟每一个居民的完整心理与逐帧寻路；
- 不直接使用从原作中提取的资产；
- 未取得授权前不设计商业化路径。

## IP与工程隔离原则

开源与免费不自动等于获得原作授权。本项目采用双层结构：

1. `simulation-core`：原创、通用、与具体IP无关的世界模拟内核；
2. `amphoreus-content`：规则配置、同人文本和自制素材组成的可卸载内容包。

仓库发布前应补充贡献者素材声明、侵权联系渠道和内容移除流程。本节是项目风险控制原则，不构成法律意见。

## 成功判据

首个核心验证成功，需要满足：

1. 同一个种子和输入可以得到完全相同的历史；
2. 无需预写专属分支，也能出现至少五类语义明显不同的终态；
3. 任何重大事件都可以追溯至少一条原因链；
4. 第二轮世界会因第一轮遗产产生可观察差异；
5. 测试者能够自发讲述至少一个人物的经历，而不只是描述数值变化。
